# ADR-0005: direct typed-array renderer and persistent relationship intent

Date: 2026-11-10. Status: implemented locally; exact verification and remaining targets are in [benchmarks](../benchmarks.md#slice-3-direct-renderer). Supersedes the interim detail renderer in ADR-0002 and the Sigma-specific renderer limitation in ADR-0004. It does not replace the worker layout or establish remote acceptance.

## Decision

The detail renderer consumes the engine-neutral projection and Float32 positions directly. WebGL2 draws instanced circular node quads and straight edge quads, with RG32F positions and an indexed RGBA8 color palette. Camera updates change uniforms, not graph buffers or a second object graph. Sigma and main-thread Graphology construction are removed. Graphology/FA2 remain exclusively in the existing worker layout; extracting its options prevents settings from retaining layout code in the main runtime graph. Both bundles are minified, including the worker before it is embedded as a string.

Node picking uses a packed CPU uniform grid with deterministic nearest-hit ties; nearby edge hover visits incident-edge CSR. Picking does not read pixels back from the GPU. Click navigation retains exact local-file resolution. Labels are Canvas-rasterized glyphs, never DOM markup or shader source. Degree-prioritized candidates and viewport-derived budgets feed collision-checked placements at seven conservative zoom LODs. Atlas dimensions, candidate count, string length and label count are bounded. Fonts or viewport size can rebuild placement; camera drawing does no per-frame label measurement or graph reconstruction. Label choices are global LOD subsets, not viewport-local re-ranking on every pan.

CSS variables `--graph-ng-bg|node|edge|group|text|accent|font` fall back to the host graph/background/font variables and validated defaults. Declared colors accept hex RGB/RGBA or a restricted CSS variable reference. `css-change` and color-scheme changes reread computed colors and upload the palette without worker calls, layout or graph-buffer replacement. A font change separately rebuilds glyphs. The initial 256-entry palette expands by rows for larger declarations.

Program linking uses nonblocking `KHR_parallel_shader_compile` completion queries when available, with timer yields and a deadline. Without the extension, driver link-status checks may still block; a hardware result cannot prove every driver. Painting is on demand through rAF plus one configurable `frameBackstopMs` timer (32 ms default) for embedded windows that withhold rAF. `shaderPollMs` defaults to 8 ms; camera bounds and label-candidate multiplier are settings too. It is not a continuous background animation loop. Context loss retains CPU arrays and disables drawing/hit interaction; restoration recompiles/reuploads. If restoration does not complete within `contextRestoreTimeoutMs` (5 seconds by default), or fails, the view switches to bounded Canvas detail or groups. Disposal removes listeners, cancels timers, explicitly loses its WebGL context and prevents failed restoration from reopening a disposed view.

Paged Canvas2D groups remain the primary overview. Software-only detail is allowed within both validated `canvasMaxDetailNodes` / `canvasMaxDetailEdges` budgets, default 2,000 visible nodes / 10,000 visible edges. Eligible edge indices are prepared once; frame drawing does not scan every hidden edge or truncate excess relationships. Larger views retain groups and member lists with a visible fallback notice. The plan's proposed 20,000-node default is deferred: the native software proof reaches 600/1,400, not 20,000 nodes, and even the conservative refusal boundary is not a measured FPS guarantee.

## Relationship-panel recovery

A native large-literal reproduction on untouched slice-2 `f24c75de` proved an existing race: a metadata refresh advanced the active revision to 2 while the retained detail dictionary still belonged to revision 1. A contribution read was rejected by the worker, the view silently swallowed the error, and the subsequent group redraw erased the selection.

A selected pair is now a durable in-view intent, not a disconnected panel node or a reused pair of dictionary indices. Local group summaries include an optional raw dictionary `key`, so a pending click can be retained before detail arrives without conflating equal-looking typed labels. Reads wait for active, group and detail generations to match. Fresh matching generations rebind the raw values to their new IDs and request the page once; stale successes and failures are ignored. Removed keys/pairs report a visible explanation rather than selecting a different relationship. Loading, refreshing, empty and failed reads are explicit, with user-triggered Retry. Source/group-definition changes, explicit navigation and closure clear the intent. Keys are captured synchronously from the exact graph the user clicked, never from a later summary with reused numeric IDs. Legacy keyless selections retain only their original display labels and remain refreshing until a fresh keyed summary resolves each label unambiguously; missing/duplicate labels are never guessed. Cached paints use a separate negative generation identity, never the live revision. Binary cache format 3 rejects/quarantines slice-2 format-2 summaries and rebuilds from public metadata. The review probe with shifted IDs under the same live revision is a regression test.

## Consequences and evidence

The renderer itself adds no runtime package. The complete shipped layout stack still audits five MIT packages, not the plan's one-package intermediate aspiration and not zero dependencies. Slice-3 bundle ceilings are enforced at 250,000 minified bytes and 70,000 gzip bytes; the later 150,000/45,000 targets remain recorded, not claimed as met.

Tests cover packed picking against a brute-force oracle, malformed coordinates, texture padding, incident edges, label collisions/LOD, color validation, settings migration, generation waits, raw-key reordering, stale promises and explicit retry. Synthetic native lanes cover actual click-open, group/detail/hover/selected screenshots in host light/dark themes, no-worker palette refresh, software fallback and hardware context restoration. The large-literal regression repeats the original first-click path and refreshes the selection. Browser measurements distinguish default group open, detail initialization, full verified memory-backed warm open, main-realm retained heap and pan/zoom frames. Exact counts and receipts belong to the benchmark record; native FPS, integrated/mobile drivers and all-scale readability remain separate gaps.
